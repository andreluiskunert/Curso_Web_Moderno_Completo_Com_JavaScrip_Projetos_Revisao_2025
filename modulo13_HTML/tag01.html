Resumo - Exercícios de HTML

Objetivo

O capítulo ensina como trabalhar com textos em HTML, mostrando o uso de cabeçalhos, parágrafos, espaçamentos e formatações básicas. A ideia é aplicar exercícios em cenários práticos, preparando para CSS e novas tecnologias.

Cabeçalhos (h1 a h6)

Representam a hierarquia de títulos: <h1> é o mais importante (como o título de um livro) e <h6> o menos relevante. Importância semântica, não tamanho do texto.

Parágrafos

Criados com a tag <p>. Espaços extras e quebras de linha não são considerados pelo navegador; para separar ideias, use novos parágrafos.

Negrito e Itálico

O negrito usa <b> e o itálico <i>. Hoje é mais comum aplicar estilos via CSS ou usar tags semânticas.

Sobrescrito e Subscrito

Usados para fórmulas e notações: <sup> (acima) e <sub> (abaixo).

22 = 4

H2O = Água

Espaços em Branco

O HTML ignora múltiplos espaços. Para inserir manualmente, use entidades como &nbsp; ou aplique espaçamento via CSS.
