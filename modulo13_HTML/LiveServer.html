Live Server

O que é?

O Live Server é uma extensão do VS Code que simula um servidor local para páginas dinâmicas e estáticas.

Por que usar?

  • Mais simples de usar que o http-server
  • Mais estável e confiável
  • Atualização automática no navegador

Como instalar?

  1. Acesse a aba de extensões no VS Code
  2. Pesquise por "Live Server" e clique em Install
  3. Clique com o botão direito em um arquivo HTML e escolha "Open with Live Server"

Pronto! Sua página será aberta automaticamente no navegador.
