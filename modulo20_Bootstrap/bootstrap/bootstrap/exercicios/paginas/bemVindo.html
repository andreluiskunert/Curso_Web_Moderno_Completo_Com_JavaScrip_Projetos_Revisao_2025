Explicação sobre Bootstrap

O que é Bootstrap?

Bootstrap é um framework front-end que ajuda a criar sites bonitos, organizados e responsivos de forma mais rápida.

Com ele, você não precisa escrever todo o CSS do zero, porque ele já traz várias classes prontas para:

  • cores
  • botões
  • menus
  • formulários
  • tabelas
  • grid de colunas
  • responsividade

Como usar o Bootstrap?

Para usar o Bootstrap, basta colocar o link do CSS no <head> do HTML. 

<link
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
  rel="stylesheet"
>

Exemplo de botão com Bootstrap

O Bootstrap possui classes prontas para estilizar elementos.

Nesse exemplo:

  • btn = define que é um botão do Bootstrap
  • btn-primary = botão azul
  • btn-success = botão verde
  • btn-danger = botão vermelho

Sistema de Grid

O Bootstrap trabalha com um sistema de 12 colunas para organizar o layout.

Coluna 2
Coluna 3

Aqui:

  • row = cria uma linha
  • col-md-4 = cria uma coluna ocupando 4 espaços de 12

Responsividade

Bootstrap ajuda o site a se adaptar em celular, tablet e computador.

Por exemplo:

  • col-12 = ocupa toda a largura no celular
  • col-md-6 = ocupa metade da largura em telas médias
  • col-lg-4 = ocupa 4 colunas em telas grandes

Vantagens do Bootstrap

  • Facilita a criação de páginas bonitas
  • Economiza tempo
  • Tem classes prontas
  • É responsivo
  • É muito usado no mercado

Conclusão

Bootstrap é uma ferramenta muito útil para quem está aprendendo HTML, CSS e desenvolvimento web. Ele permite criar interfaces modernas usando classes prontas, deixando o código mais rápido de montar.
